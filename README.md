# Электронная очередь ЦЗН Тульской области

Веб-система для работы электронной очереди в локальной сети учреждения:

- киоск посетителя: выбор услуги и выдача талона;
- АРМ оператора: вызов следующего, повтор, завершение и отметка «не явился»;
- телевизор/табло: текущие вызовы, последние вызовы, часы и ротация рекламы;
- администрирование: услуги, загрузка изображений/видео и настройка текста талона;
- у каждой услуги свой префикс талона: например «Резюме» → `Р001`, «Соцвыплаты» → `С001`;
- при оформлении талона киоск запрашивает тип/номер документа и телефон;
- логотип можно загрузить в админке: он отображается на киоске, табло, АРМ, странице талона и в шапке системы;
- киоск адаптирован под вертикальный экран и использует крупные сенсорные кнопки;
- роли пользователей: администратор, оператор АРМ и пользователь отчётов;
- оператор АРМ закрепляется за конкретным окном, повторно выбрать другое окно через API нельзя;
- отчёты показывают среднее время работы с посетителем от вызова до завершения.
- отчёты по периоду и услугам;
- приоритет услуг и нормативное время обслуживания;
- отложенный приём и переадресация талона на другую услугу;
- голосовое объявление номера талона на табло;
- оценка обслуживания посетителем;
- журнал действий пользователей и операторов;
- SQLite, работа без отдельного сервера баз данных;
- печать на Windows-термопринтер через `pywin32` или печать из браузера;
- сборка в Windows `.exe` через PyInstaller.

## Быстрый запуск в Windows

1. Установите Python 3.11 или новее.
2. Откройте PowerShell в папке проекта.
3. Выполните:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Откройте [http://127.0.0.1:8000/kiosk](http://127.0.0.1:8000/kiosk).

Основные экраны:

- `/kiosk` — киоск;
- `/operator` — АРМ окна;
- `/display` — телевизор/табло;
- `/admin` — администрирование, пароль по умолчанию `admin`;
- `/reports` — отчёты.

Для работы с других устройств в локальной сети задайте в `.env`:

```env
HOST=0.0.0.0
PORT=8000
ADMIN_PASSWORD=сложный-пароль
PRINTER_NAME=Название принтера Windows
BROWSER_AUTO_PRINT=true
AUTO_PRINT=false
```

После этого устройства открывают `http://IP_СЕРВЕРА:8000/kiosk`, `.../operator` или `.../display`.

## Сборка в EXE

```powershell
.\build_windows.ps1
```

Результат: `dist\QueueTula\QueueTula.exe`. Рядом с исполняемым файлом можно хранить `.env`, а папку `data` система создаст автоматически.

## Печать

Основной сценарий — автопечать из браузера: после выдачи талона открывается страница талона и вызывается `window.print()`. В обычном браузере появится системный диалог печати. Для полностью бездиалоговой печати на киоске Chrome/Edge нужно запускать с политикой киоска (`--kiosk-printing`) и заранее выбрать термопринтер по умолчанию.

`AUTO_PRINT=true` оставлен как альтернативный серверный режим RAW-печати через `pywin32`. Для него задайте `PRINTER_NAME`. Обычно для киоска удобнее браузерный вариант: он использует штатный драйвер Windows и настройки формата бумаги.
